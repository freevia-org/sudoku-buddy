# Play Store screenshots

Captured on 8 October 2026 from signed release 1.0.0 (120), installed from APKs
generated by bundletool 1.18.3 from the final AAB. AAB SHA-256:
`57AFB7C83E84C182826EBEA270F3CF5E8A9DD5C9BE547558C0AC9DB78719F9C9`.

All five show actual captures from a OnePlus CPH2449 running Android 16. They were
losslessly re-encoded as 24-bit RGB PNGs for Play's no-alpha requirement; every
rendered RGB pixel was compared with the original and is unchanged.
The Android display was temporarily set to 1080 x 2160, giving a 2:1 aspect ratio
within Play's screenshot limits. Font scale was 1.0. The original 1080 x 2412
display and font scale were restored after testing. No pixels were retouched,
composited or generated. The user positioned the paper Sudoku for the camera view.

2. `02-puzzle.png` — Read view distinguishing printed clues, handwritten answers
   and pencil marks after correcting one flagged note cluster.
3. `03-check.png` — green checks on handwritten answers and a fully visible result.
4. `04-hint.png` — final hint answer with Replay reasoning and Close hint controls;
   the scrollable explanation documents ten deductions leading to the answer.
5. `05-history.png` — current saved scan and older entries preserved by the upgrade.
